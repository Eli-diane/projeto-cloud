# ADR 002 — Usar DBaaS PostgreSQL da Magalu Cloud

**Status:** Aceito  
**Data:** 08/08/2026

---

## Contexto:

A aplicação precisava guardar os dados de forma segura e permanente, os pedidos e itens não poderiam sumir quando o container fosse reiniciado.

Além disso, como a API tem 2 réplicas (pods), o banco precisava aceitar conexões de múltiplos pods ao mesmo tempo, sem conflitos.

---

## Alternativas consideradas:

| Opção | O que é | Prós | Contras |
|-------|---------|------|---------|
| **DBaaS PostgreSQL** | Banco gerenciado pela Magalu Cloud | Backup automático, patches de segurança, sem precisar gerenciar servidor | Custo por hora de uso, menos controle sobre configurações avançadas |
| **PostgreSQL em pod com PVC** | Banco rodando dentro do Kubernetes, com volume persistente | Custo baixo, tudo no mesmo lugar | Backup e recuperação por nossa conta; o dado morre junto com o cluster |

---

## Decisão:

**DBaaS PostgreSQL da Magalu Cloud**, um banco gerenciado fora do cluster.

**Critério principal:** disponibilidade e custo de operação. Gerenciar um banco de dados (backup, recuperação, patches) é caro e trabalhoso, terceirizar isso para a nuvem vale o custo adicional.

---

## Consequências:

### Positivas

- Backup automático e patches de segurança feitos pelo provedor
- O banco sobrevive a qualquer redeploy do cluster (os dados não somem)
- Múltiplos pods podem se conectar ao banco ao mesmo tempo sem conflito
- Alta disponibilidade incluída no serviço
- Não precisamos de uma pessoa dedicada para administrar o banco

### Negativas

- Custo por hora de uso, mesmo com pouco tráfego
- Menos controle sobre configurações avançadas do PostgreSQL (ex: tuning fino)
- Dependência do provedor para upgrades de versão

---

## O que isso significa na prática?

| Pergunta | Resposta |
|----------|----------|
| Os dados sobrevivem a um redeploy? | Sim, o banco é externo ao cluster. |
| Posso acessar o banco de fora? | Sim, mas ele fica em uma sub-rede privada, o acesso é controlado. |
| Preciso gerenciar backups? | Não, o provedor faz isso automaticamente. |
| O que acontece se o banco cair? | A API para de funcionar até o banco voltar, mas o provedor garante alta disponibilidade. |
